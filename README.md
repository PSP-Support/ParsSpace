# 🕷️ Pars Space Panel

## 🚀 معرفی پروژه

**Pars Space Panel** یک پنل مدیریتی مدرن و اختصاصی برای مدیریت سرویس‌ها،
کاربران و کانفیگ‌ها است.

ویژگی‌های اصلی: - 🎨 طراحی مدرن Liquid Glass - 🌙 حالت تاریک و ☀️ روشن -
🌐 زبان فارسی و انگلیسی با RTL/LTR - 👤 مدیریت کاربران - ⚙️ مدیریت
کانفیگ‌ها - 🔗 سیستم Subscription اختصاصی - 📊 داشبورد آماری - 📱 طراحی
واکنش‌گرا برای موبایل و دسکتاپ

------------------------------------------------------------------------

# 🛠️ راه‌اندازی

## پیش‌نیازها

-   Python 3.10+
-   Git

## دریافت پروژه

``` bash
git clone https://github.com/yourusername/ParsSpacePanel.git
cd ParsSpacePanel
```

## نصب وابستگی‌ها

``` bash
pip install -r requirements.txt
```

## تنظیمات محیطی

فایل `.env`:

``` env
ADMIN_USERNAME=your_username
ADMIN_PASSWORD=your_secure_password
SECRET_KEY=your_secret_key
```

## اجرا

``` bash
python main.py
```

پس از اجرا:

    http://localhost:PORT

ParsX runtime directory

The Pars Space server downloads the upstream Xray-core Linux amd64 release v26.9.9
at startup and stores the executable here as `parsx`.

ParsX is the Pars Space runtime name for the Xray-core engine. Upstream Xray-core
remains MPL-2.0 and is not represented as an independent upstream project.

For source builds, use the separate ParsX build package supplied with this release.
